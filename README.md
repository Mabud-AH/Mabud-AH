### 🤖 My Telegram Bot Project

A powerful inventory management bot built with Python.

#### 🚀 Features

- **Material Management:** Track input/output of materials
- **IQF Handling:** Process IQF returns with TT numbers
- **Reporting:** Generate Excel reports for inventory, inputs, outputs
- **Search:** Find materials by name/code or MR/IQF numbers
- **Dashboard:** View inventory stats at a glance
- **Admin Controls:** Restricted upload/management features

#### ⚙️ Setup Requirements

- Python 3.9+
- Telegram Bot Token
- SQLite database
